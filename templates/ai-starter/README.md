# ai-ml-starter

Starter project generated by `ai-ml-dev-bootstrap`.

## Environment

The new macOS `ai` feature uses `pyproject.toml` and `uv.lock` as the source of
truth:

```bash
uv sync --extra ai --extra personal
```

Restricted/local-first variant:

```bash
uv sync --extra ai --extra restricted
```

Add ML systems tooling:

```bash
uv sync --extra ai --extra personal --extra mlsys
```

The `requirements/` files remain for Windows/WSL and older starter-project
compatibility, but new macOS projects should use `uv sync`.

## Commands

```bash
uv run python scripts/check_env.py
uv run jupyter lab
uv run ruff check .
uv run pytest
```

## Profiling example

```bash
uv run python scripts/profile_torch.py
uv run tensorboard --logdir runs
```

On Apple Silicon, the `ai` extra includes PyTorch's macOS/MPS wheels and adds
MLX/MLX-LM through platform markers. CUDA-only packages remain a Linux/WSL
project concern.
